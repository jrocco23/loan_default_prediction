## Introduction
This repository contains a machine learning project that focuses on predicting loan default using historical lending data. The goal is to build a reliable predictive model based on loan history that can accurately classify prospective applicants who are likely to default, based on specific parameters, in order to automate/assist the loan approval process.

## Context
Defaulted loans are a big problem for banks. Indeed, a lot of defaulted loans will lead to significant financial losses for banks. That's why it is important for banks to proactively identify applicants who are highly likely to default, in order to minimize risk and make more informed, profitable lending decisions.

## Key Questions:

1. Which applicant characteristics (e.g., credit history, job type, debt-to-income ratio) should we focus on as the **main drivers of loan default**?
2. How can we **best balance the trade-off** between catching risky loans (Recall) and accidentally rejecting good customers (Precision)?
3. Which machine learning algorithm provides the **best balance of accuracy and interpretability**?
